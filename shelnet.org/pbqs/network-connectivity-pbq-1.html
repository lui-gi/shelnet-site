Practice PBQ Scenario

You are a help desk technician. A user reports they cannot access any websites. Your task is to diagnose the network connectivity issue using the command line.

Suggested Steps:

  1. Check the computer's IP configuration.
  2. Verify connectivity to the default gateway (192.168.1.1).
  3. Test DNS resolution by pinging a public website (e.g., google.com).
  4. If DNS fails, test connectivity to a public DNS server (e.g., 8.8.8.8).
