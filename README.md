# Shelnet

Welcome to **Shelnet**, an independent learning hub built to help students prepare for CompTIA A+ and other IT certifications.  
The goal of this site is to provide **free, high-quality, hands-on study tools** — including interactive PBQs (Performance-Based Questions), practice exams, and tutorials — all accessible in a simple web format without logins or ads.

---

## 🌐 Site Overview

Shelnet is designed for students who prefer a clear, distraction-free environment for exam prep.  
All resources are completely browser-based and self-contained, so they can be used online or offline after downloading.

### Key Features
- Free, open-access CompTIA A+ practice environment  
- Interactive PBQs covering real exam objectives  
- Organized navigation by domain (Core 1 and Core 2)  
- Responsive layout for desktop and mobile  
- No external dependencies or sign-ups required  

---

## 📁 Pages and Structure

| Page | File | Description |
|------|------|-------------|
| **Home** | `index.html` | The main landing page. Introduces Shelnet’s mission, explains what the site offers, and links to PBQ practice sections and study resources. |
| **Practice PBQs** | `pbqs.html` | A grid of available performance-based questions for CompTIA A+ (Core 1 and Core 2). Each tile links to a fully interactive PBQ page. |
| **Practice Exam** | `exam.html` | A full-length A+ practice exam that simulates the actual testing environment. Includes randomized questions and a results summary. |
| **About** | `about.html` | Background on the Shelnet project — who built it, the motivation behind providing free study tools, and how to contribute or suggest improvements. |
| **Contact** | `contact.html` | Simple contact information and/or feedback form for users who wish to reach out, suggest PBQs, or report errors. |
| **PBQ Pages** | `/pbqs/*` | Individual HTML files for each PBQ (e.g., `pbq1.html`, `pbq2.html`, etc.). Each presents a unique troubleshooting or configuration task aligned with CompTIA exam objectives. |
| **Assets Folder** | `/assets/` | Contains images, icons, and supporting visual files used across the site. |
